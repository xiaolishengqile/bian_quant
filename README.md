# 合约量化工作台

个人使用的币安稳定币计价永续合约自动交易网页。配置币种、周期、杠杆、资金和风控后，后台按已收盘行情计算平滑异同移动平均线指标，金叉开多、死叉开空；反向信号先平仓，确认空仓后再按选项决定是否反向开仓。

默认是**演示行情的模拟盘、停止运行、零持仓**。演示价格是程序生成的数据，仅用于体验和功能验证。

第一次接触量化交易，可先阅读[项目入门与金融知识](docs/项目入门与金融知识.md)，了解当前缺口、完整流程、技术选型、常用命令和金融计算口径。

## 本机启动

需要 Python 3.11 及以上、Node.js 22 及以上。

上面分别是后端编程语言运行环境、前端脚本运行环境。

```sh
python3 -m venv .venv
.venv/bin/pip install --index-url https://pypi.org/simple -r requirements.lock
npm --prefix frontend ci
npm --prefix frontend run build
.venv/bin/python -m backend
```

这些命令依次创建隔离环境、安装后端依赖、安装前端依赖、构建网页、启动服务。

打开 [本机工作台](http://127.0.0.1:8765)。后台进程运行时，关闭浏览器不会停止策略；电脑睡眠、关机或退出后台进程会停止执行。要全天运行，应部署到持续在线的服务器。

开发界面时，额外运行以下命令，访问 [开发预览](http://127.0.0.1:5173)：

```sh
npm --prefix frontend run dev -- --host 127.0.0.1
```

该命令启动支持自动刷新的前端开发服务，后端仍需运行。

## 使用方式

1. 在“策略配置”选择交易币种、周期和参数，保存后启动。
2. 初次启动仅记录当前已收盘行情，等待下一次新交叉，不补做历史交易。
3. “停止策略”禁止新开仓，已有仓位仍按止盈止损规则管理；“全部平仓”会先停止策略再平仓。
4. 运行中或有持仓时不允许修改交易配置，避免已有仓位的风险规则被意外改变。
5. 模拟资金、成交和持仓保存在本机数据库。演示模拟、真实行情模拟、测试网、实盘各自保存资金及历史；停止且无持仓时可以切换，切回后恢复对应账户。重置模拟盘只清空当前模拟账户的成交，必须先停止并平仓。

## 交易环境

| 模式 | 行情 | 是否操作交易所资金 |
| --- | --- | --- |
| 模拟盘＋演示行情 | 程序生成并明确标注 | 否 |
| 模拟盘＋币安行情 | 币安真实合约行情 | 否 |
| 币安测试网 | 币安测试环境行情 | 仅测试资产 |
| 实盘 | 币安真实合约行情 | 是，需专门开启并配置密钥 |

真实行情连接失败会显示错误、停止开仓，不会静默切换到演示价格。

复制 `.env.example` 为 `.env`，只在本机或服务器填写。密钥不会发送到网页，也不应提交到版本管理。

| 环境变量 | 用途 |
| --- | --- |
| `BINANCE_TESTNET_API_KEY` / `BINANCE_TESTNET_API_SECRET` | 币安测试网接口标识和签名密钥 |
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | 币安实盘接口标识和签名密钥 |
| `ENABLE_LIVE_TRADING=true` | 明确允许该部署使用实盘 |
| `CONSOLE_PASSWORD` | 控制台口令，远程或实盘至少十二位 |
| `CONSOLE_ALLOWED_HOSTS` | 允许访问的域名，多个用逗号分隔，不带协议和端口 |
| `QUANT_DB_PATH` | 数据库文件路径，默认在本项目数据目录 |

实盘使用前先完成测试网联调。首版仅支持单向持仓、单资产保证金账户；不接管已有外部仓位或挂单，也不自动改动账户全局模式。杠杆选择范围为一至二十倍，最终须符合交易所限制。每个账户只应由一个本程序实例管理，不要同时在币安客户端或其他程序手动交易同一仓位。

请求超时并不等于下单失败。系统会查询原订单，无法确认时停止自动执行，保留订单意图以防重复下单。这时应先到币安核对仓位与订单；第一版没有自动解除未知订单锁的功能，需要核对并修复本地记账后再恢复，不能靠反复点击启动重试。交易所明确尚未收到的本地校验失败会记为拒单，可修改参数后启动。

## 资金和指标口径

- 单笔金额指**保证金**；下单名义金额约为单笔保证金乘以杠杆。模拟费用和滑点按名义金额计算。
- 止盈、止损比例按标的价格涨跌计算，**不是**保证金收益率。杠杆会放大保证金收益和亏损。
- 每日亏损限制按协调世界时自然日计算，计入已实现和浮动变化；触发后禁止开仓并执行风险处理，停止状态仍管理已有仓位。真实账户会周期同步钱包余额，资金费及实际费用会进入权益变化；充值、提现也会影响当日权益差额，第一版不单独剔除资金转入转出。
- 每日亏损一旦触发，会保存当日锁定标记；行情反弹或服务重启不会解除锁定，未平仓位在恢复连接后继续风险退出。下一自然日解除开仓锁定，但需手动启动；跨日停机期间无法还原精确零点权益，日基准采用最近保存权益。
- 尚未连接交易所时，界面不把策略初始资金显示为真实账户余额。已实现盈亏为本策略成交损益，不能当作交易所所有活动的完整账单。无法取得精确手续费时会标注估算并记录日志。
- 模拟与回测不完整模拟资金费率、强平、订单簿冲击或真实成交延迟，因此不能把结果视作实盘收益预测。
- 回测使用最近最多一千根行情；上一根收盘产生信号、下一根开盘模拟成交，计入配置的手续费和滑点，不提前使用未来价格。图表中正在形成的行情不会当成已收盘交易信号。
- 后台按五秒周期轮询，不属于高频交易系统。后台或网络中断时，本地风控不能保证实时退出；首版未配置交易所托管止损单。

## 服务器部署

项目包含容器部署文件。先填写 `.env` 的控制台口令，运行：

```sh
docker compose up -d --build
```

该命令构建网页和后端，并让容器在故障后自动重启。数据持久化到独立数据卷。**交易状态是否恢复以控制台显示为准，实盘重启不自动继续开仓。**

默认端口仅绑定服务器本机。可通过安全隧道访问；若使用反向代理公开访问，需要配置加密连接和允许的域名。不要增加后台工作进程数量，应用同时通过数据库锁阻止同一数据库启动多个交易循环。

## 验证

```sh
.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend test
npm --prefix frontend run build
```

这些命令分别验证后端交易和接口行为、前端配置校验、前端正式构建。自动测试不使用账户密钥，不发送真实交易。
