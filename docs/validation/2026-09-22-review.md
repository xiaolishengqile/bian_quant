## 已修复的实际问题

| 原行为 | 修改后 |
| --- | --- |
| 当日亏损触发后，部分仓位因行情故障未平，随后反弹可能解除限制 | 保存当日风险锁定，恢复行情后继续退出，重启不解除，次日才清除 |
| 真实账户启动先检查旧余额，更新余额后没有重查每日亏损 | 同步余额后再次检查，达限拒绝启动 |
| 回测开仓成本已触发日亏损或止损，仍可能等待后续价格 | 开仓后立即按当时价格风控退出，避免虚增收益 |
| 测试网选择币种使用实盘列表 | 按交易环境分别拉取和缓存 |
| 部分错误周期或缺段蜡烛可能进入指标 | 拦截缺段、重复、倒序、周期不符及负成交量 |
| 极低价格显示为零，止盈止损难以区分 | 自适应显示价格精度 |
| 带取消信号的行情请求没有超时限制 | 同时保留取消与超时 |
| 负数盈亏导出为文字，“全部成交”未说明只取最近记录 | 保留数值类型并标明最多 200 条及筛选范围；累计盈亏标明口径 |

## 真实历史样本

读取币安公开合约行情后本地模拟，没有下单。样本均为 15 分钟、999 根已收盘蜡烛，北京时间 2026-09-12 09:15 至 2026-09-22 18:59:59。使用默认指标参数 12/26/9；每币独立本金 10000 泰达币、单笔保证金 100、3 倍杠杆、价格止损 2%/止盈 4%、单边手续费 0.04%、单边滑点 0.02%，反向先平再反手。

| 比特币 | -33.8308 | -0.3383% | 0.4434% | 76 | 18.2511 |
| 以太坊 | -27.6368 | -0.2764% | 0.5990% | 76 | 18.2515 |

三个样本均亏损；只能说明该窗口内默认参数的结果，不能推断未来表现。收益和回撤相对于完整本金，单笔占用很小；三个独立结果不能相加视为组合。回测不含资金费、强平、盘口深度和真实延迟，收盘权益回撤也可能低估盘中回撤。演示行情回测仅用于验证流程，不能用于判断盈利。
