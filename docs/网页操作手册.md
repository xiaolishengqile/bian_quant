# 衡量量化工作台：网页操作手册

这份手册写给直接使用网页的人。按“进入网页 → 配置 → 回测 → 启动 → 查看 → 停止”的顺序操作即可。页面金额以泰达币计价。

USDT

中文：泰达币在交易对中的代码，例如“比特币／泰达币”表示比特币合约以泰达币计价。

> **第一次使用，先保持默认的“模拟盘＋演示行情”。** 演示行情由程序生成，只适合熟悉按钮和检查流程。测试网和实盘的准备工作见第 8 节。

## 1. 打开网页并登录

1. 请先确认后台服务已经启动。本机使用时，打开[本机工作台](http://127.0.0.1:8765)；部署在服务器时，打开管理员提供的网址。
2. 如果看到“回到你的交易工作台”，输入**服务器访问口令**，点击“进入工作台”。本机未设置口令时可能直接进入。
3. 进入后，先看顶部是否显示“服务已连接”，再看页脚的“最近同步”时间。显示“连接异常”时，页面可能仍保留上一次成功读取的数据，先点击“重试”或顶部刷新按钮。

页面左侧有五个入口：**总览、策略、成交、回测、设置**。左下角“说明”可随时查看几个重要按钮的含义。手机上入口的位置可能随布局调整，名称相同。

## 2. 第一次体验：最短操作顺序

1. 打开**策略**页，确认交易模式是“模拟盘”、行情来源是“演示行情 · 仅供体验”。
2. 先保留默认币种和参数。若做了改动，点击右侧“**保存策略配置**”；看到“已与服务器配置同步”才算保存成功。未修改参数时，保存按钮会不可点击。
3. 打开**回测**页，选择一个合约，点击“**运行历史回测**”。这是历史演练，不会开仓。
4. 返回**总览**，核对顶部模式、币种、周期、单笔保证金与杠杆，然后点击页面顶部“**启动策略**”。
5. 状态变为“运行中”后，观察“当前持仓”和“运行日志”。启动时只记录最近一根已收盘行情，等待后续**新的交叉信号**；不会立刻补做过去的交易。
6. 想暂停新交易，点击“**停止策略**”。想退出已有仓位，在总览点击“**全部平仓**”，阅读弹窗后再确认，并核对持仓是否归零。

**保存配置不会启动策略；运行回测也不会启动策略。**

## 3. 在“策略”页填写参数

页面按“交易环境 → 信号与执行 → 资金与风险限制 → 模拟与回测成本”排列。改完后查看右侧“配置摘要”，再保存。币种至少选 1 个、最多 8 个；当前只提供一套策略参数，所选币种共用这些参数。

### 交易环境

| 页面字段 | 怎么选 | 会产生什么影响 |
| --- | --- | --- |
| 交易模式 | 模拟盘、测试网或实盘 | 模拟盘使用虚拟资金；测试网会操作测试资产；实盘会操作真实资金 |
| 行情来源 | 模拟盘可选演示行情或币安真实行情；其余模式固定为币安行情 | 演示价格是生成数据；币安行情需要网络正常 |
| 信号周期 | 选择 1 分钟至 1 天的可用周期，默认 15 分钟 | 决定策略按哪种已收盘蜡烛判断信号 |
| 交易币种 | 搜索并勾选，默认比特币和以太坊 | 策略监测所选合约；多个币种共用资金与风险上限 |

如果从演示行情切换到币安行情，**先保存配置**，等币种列表按新环境刷新，再选择其他合约。切换模式或行情来源时，会切换到该环境独立保存的账户资金和历史。

### 信号与执行

MACD

中文：指数平滑异同移动平均线。本项目使用快线、慢线和信号线的交叉作为交易信号，不代表交叉后价格一定按预期变化。

| 页面字段 | 默认值 | 怎么理解 |
| --- | ---: | --- |
| 快线周期／慢线周期／信号线周期 | 12／26／9 | 按蜡烛根数计算；快线周期必须小于慢线周期 |
| 反向信号后反手开仓 | 开启 | 出现反向信号时先平旧仓，再尝试开相反方向；关闭后只平旧仓 |
| 杠杆倍数 | 3 倍 | 单笔计划名义金额约为“单笔保证金 × 杠杆”；网页允许 1～20 倍，交易所仍会检查自己的限制 |
| 保证金方式 | 逐仓 | 可改为全仓。真实交易会向交易所设置所选模式；模拟和回测没有完整模拟强平差异 |

### 资金与风险限制

| 页面字段 | 默认值 | 填写时要明白的事 |
| --- | ---: | --- |
| 策略资金 | 10,000 泰达币 | 模拟账户起始金额；填写这个数字不会给真实账户充值 |
| 单笔保证金 | 100 泰达币 | 每次计划占用的担保资金，不是杠杆后的仓位金额 |
| 总保证金上限 | 1,000 泰达币 | 本程序所有仓位合计可占用的保证金上限 |
| 每日净亏损上限 | 200 泰达币 | 当日权益损失触及该值时暂停开仓并尝试退出；不是保证最多只亏这么多 |
| 价格止损幅度 | 2% | 以开仓价格为基准，价格向不利方向变化时触发退出 |
| 价格止盈幅度 | 4% | 以开仓价格为基准，价格向有利方向变化时触发退出 |

**三个资金数字的关系必须满足：单笔保证金 ≤ 总保证金上限 ≤ 策略资金。** 默认设置下，一笔计划名义金额约为 100 × 3＝300 泰达币。止盈止损填写的是**币价涨跌幅**，不是加杠杆后的保证金收益率。

每日亏损按协调世界时自然日计算；北京时间每天早上 8 点换日。触发后，当天不会因为价格反弹或重启自动恢复开仓；跨日解除锁定后仍需手动启动。

### 模拟与回测成本

“单边手续费”默认 4 基点，“单边滑点”默认 2 基点；**1 基点＝0.01%**。模拟盘和回测用这两个值估算交易成本。真实交易以交易所返回的成交价格和费用为准；费用明细读不到时，页面和日志会标注估算。

填写完成后点击“**保存策略配置**”。“恢复已保存配置”会放弃当前尚未保存的编辑。策略运行中或还有持仓时不能修改交易配置；应先停止并确认平仓。存在状态未知的订单时，后台也会拒绝修改。

## 4. 先用“回测”页看历史演练

1. 先在**策略**页保存参数；回测只使用服务器**已保存**的配置，不采用页面里尚未保存的改动。
2. 打开**回测**，选择“回测合约”和“蜡烛周期”，点击“运行历史回测”。这里临时改“蜡烛周期”只影响这一次回测，不会改策略的信号周期。
3. 查看“累计收益率、最大回撤、平仓交易、胜率、累计手续费”和“账户权益曲线”。继续阅读页面下方的“回测口径与限制”。

回测每次只分析**一个币种最近最多 1,000 根行情**；多个币种的结果分别使用完整初始资金，不能直接相加当成真实多币种组合收益。演示行情的回测只能检查流程；真实行情回测也没有完整计入资金费、强平和真实成交延迟。运行回测**不会下单，也不会改变当前持仓**。

## 5. 启动后在“总览”页怎么看

点击顶部“启动策略”后，先确认顶部状态，再查看以下内容：

| 位置 | 看什么 | 如何理解 |
| --- | --- | --- |
| 页眉状态 | 已停止／运行中／异常暂停／风控暂停 | “运行中”表示策略在监测新信号，不表示已经开仓 |
| 账户统计 | 账户权益、当日净盈亏、占用保证金、已完成交易 | 测试网或实盘尚未同步账户时，部分金额显示“—” |
| 策略概览 | 监测合约、信号周期、杠杆、保证金方式、风险参数 | 用来核对实际保存并执行的配置 |
| 当前持仓 | 方向、数量、入场价、浮动盈亏等 | 没有持仓时为空；“已完成交易”按平仓次数统计 |
| 运行日志 | 启动、成交、风控和连接错误 | 出现异常先看这里和页面顶部的“策略提示” |

总览中的行情图可以切换币种和图表周期，**只改变你看到的图，不改变已保存的策略配置**。图表可能显示尚未收盘的蜡烛，策略开仓信号只读取已收盘蜡烛。页面会自动刷新；关闭浏览器后，只要后台仍在运行，策略仍会执行。

## 6. 暂停、平仓、查看记录

| 你想做什么 | 点击哪里 | 结果 |
| --- | --- | --- |
| 暂停新开仓 | 页面顶部“停止策略” | 停止新的策略开仓；已有持仓仍由在线的后台尝试执行止盈止损 |
| 退出所有策略持仓 | 总览 →“全部平仓”→弹窗中“确认全部平仓” | 先停止策略，再逐笔尝试平仓；操作后检查当前持仓和成交记录 |
| 看买卖记录 | 左侧“成交” | 查看最近成交与运行日志；一次完整开仓到平仓会产生多条订单记录 |
| 下载记录 | 成交页按合约／原因或成交类型筛选，点击“导出筛选记录” | 只导出当前筛选结果；网页最多读取最近 200 条订单，不是全部历史 |

“全部平仓”可能因行情或交易所连接失败而未能完成。不要仅凭按钮点击成功判断仓位已清零；以刷新后的持仓和交易所账户为准。后台退出、电脑休眠或断网时，本地止盈止损无法继续工作，当前版本没有交易所托管止损单。

## 7. “设置”页能做什么

- “交易所连接”显示测试网、实盘密钥及实盘开关**是否已配置**。这里不能填写密钥；“已配置”也不等于权限、余额和下单已经验证成功。
- “访问与运行环境”显示控制台口令、当前交易环境和持久化状态。登录口令与交易所密钥不是一回事。
- “重新开始一次模拟”可以把**当前模拟账户**恢复到已保存的策略资金，并清空它的成交记录。只能在模拟盘、策略不运行且没有持仓时点击“重置模拟账户”。操作不能撤销，需要留存当前可见记录时先在“成交”页导出。

## 8. 切换到真实行情、测试网或实盘

| 目标 | 网页上的操作 | 额外前提 |
| --- | --- | --- |
| 真实行情模拟盘 | 策略 → 选“模拟盘” → 行情来源选“币安真实行情” → 保存 | 需要能连接币安公开行情；仍只使用虚拟资金 |
| 测试网 | 策略 → 选“测试网” → 保存 → 启动 | 管理员先在服务器配置独立的测试网交易密钥；启动时再检查权限和账户状态 |
| 实盘 | 策略 → 选“实盘” → 保存 → 再核对总览并启动 | 管理员先配置真实账户交易密钥、实盘开关、至少 12 位控制台口令；网页还会要求确认真实资金交易 |

网页**不能输入或查看交易所密钥**。需要部署者按[项目说明](../README.md)设置服务器，再重新启动后台。切换环境前先停止策略并确认当前账户没有持仓；切回来时会恢复该环境原有的本地资金和历史。

目前测试网真实账户的开平仓、费用及故障恢复还缺完整联调证据，且没有交易所托管止损。**不要把“设置页显示已配置”当作“可以无人值守实盘”的证明。**

## 9. 常见提示怎么处理

| 看到的情况 | 先做什么 |
| --- | --- |
| “连接异常”或“暂时无法连接服务” | 检查后台是否仍在运行，再点页面“重试”；当前显示的可能是上次成功同步的数据 |
| “行情暂不可用”“行情已过期” | 核对行情来源、网络和服务时间，稍后刷新；币安行情失败时不会自动改用演示价格 |
| 已启动但没有成交 | 先确认状态为“运行中”，再等**新的收盘交叉信号**；启动时不会追补旧信号 |
| 配置无法编辑或保存 | 先停止策略、平仓，并检查是否存在未知订单；同时检查币种数量和资金大小关系 |
| 显示“风控暂停” | 查看当日净盈亏和策略提示；当日亏损锁定后，跨日解除仍需手动启动 |
| 显示“异常暂停”或“订单状态未知” | 先核对交易所订单、仓位和本地记录；不要反复点启动或重发订单，当前网页没有未知订单的自助解锁功能 |
| 真实账户持仓与页面不一致 | 暂停操作，到交易所核对；程序不会自动接管外部手动交易产生的仓位 |
| 设置页显示密钥“已配置”但无法启动 | “已配置”仅说明服务器检测到配置；查看具体策略提示，核对权限、余额、持仓模式和挂单 |

想了解保证金、杠杆、资金费、回测统计等概念，可阅读[项目入门与金融知识](项目入门与金融知识.md)。
