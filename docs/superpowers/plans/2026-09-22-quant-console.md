# 合约量化工作台实施计划

目标：交付可启动、可配置、可模拟运行的完整个人量化网页及服务端交易适配。
依据：[设计方案](../specs/2026-09-22-quant-console-design.md)。用户要求直接实施。

## 模块与顺序
1. 定义共享配置与接口类型；安装运行依赖。
2. 并行实现：交易运行引擎和回测、币安行情与下单适配、中文前端工作台。
3. 实现服务端接口、会话安全、后台循环和持久化集成。
4. 运行单元与接口测试；使用浏览器验证配置、启停、图表、回测、响应式布局。
5. 独立审查交易安全和关键业务流程，修复问题，完成中文说明与代码提交。

## 关键测试
- 金叉/死叉发生在相邻两根已收盘蜡烛；指标预热不足不得开仓。
- 反向交易须先平仓；平仓失败或状态未知不得开反向仓。
- 重复轮询同一根蜡烛不得重复开仓；重启后仍不重放。
- 达到亏损限额后不得再开仓；停止期间仍执行已有仓位风险退出。
- 行情失效、密钥缺失、非法参数、交易模式切换均有明确拒绝与界面提示。
- 回测不使用未来数据成交，手续费/滑点影响结果，不能称作盈利预测。
